OI Helper MCP 快速配置

填写路径 → 选择客户端 → 复制配置. 无需手动拼 JSON.

前置条件: 已安装 Node.js, 且已构建 core 生成 oi-judge (默认位于 core/build/oi-judge). MCP Server 会调用它完成评测.
1填写路径
2评测默认
3站点凭据
4提交防护
5原题
6选择客户端
7复制配置
mcp.json 

            

        


        

            
8可用工具

            

                

                    judge_problem
                    
评测整个题目目录 (读取 problem.json), 支持 env / jobs / timeLimit / memoryLimit / standard / optimize / checker / format / eps.

                

                

                    judge_file
                    
评测单个源文件, 指定输入与期望输出.

                

                

                    judge_version
                    
返回 oi-judge --version 的版本信息.

                

                

                    fetch_problem
                    
抓取题目页 (xmoj/洛谷) 并生成题目目录.

                

                

                    fetch_original
                    
抓取原题 (洛谷/CF/AtCoder/Hydro) 题面与样例.

                

                

                    fetch_contest
                    
抓取竞赛题目 (/web/contest/{cid}/{num}).

                

                

                    fetch_extra
                    
下载竞赛「更多样例」压缩包并解压.

                

                

                    submit_solution
                    
提交源码到 xmoj (题目页 URL), 凭据取自环境变量.

                

                

                    submit_original
                    
直连提交源码到原题 (洛谷/CF/AtCoder/Hydro); 遇图形验证码时回传图片与 cookie, 识别后带 captcha 重试.

                

                

                    query_submission
                    
查询某个提交的评测结果 (xmoj/luogu/hydro).
