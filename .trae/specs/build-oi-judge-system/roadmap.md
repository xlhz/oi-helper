# 下一版本预更新说明（Roadmap）

首期（v1）范围：评测核心 CLI、题目目录包与手动选文件、传统题全部能力（多测试点、强制时限内存、CCF 比对、SPJ、subtask）、交互题、提交答案题、通信题、强隔离、结果 JSON、VSCode 插件全量交互、本地 REST API、MCP Server。

以下为**不纳入首期**、留待下一版本的计划项。

## 批量与成绩

- 同题多代码批量评测：同一题目下评测多个选手代码，生成排名与成绩单。
- 多题目批量：一次选择多个题目目录，依次评测。

## 结果导出

- 在面板 + JSON 基础上，新增导出 HTML/CSV 成绩单，适合测评他人/班级场景。

## 其他题型扩展

- 按洛谷/CCF 后续需要，评估新增题型（如捆绑测试的更多组合、特殊输入约定等）。

## 其他候选

- 题目配置可视化编辑面板。
- 评测历史记录与结果对比（回归）。
- 更多语言支持（当前仅 C++，SPJ 亦为 C++）。
- 更细粒度的沙箱策略（网络完全禁用、文件系统只读挂载白名单）。
